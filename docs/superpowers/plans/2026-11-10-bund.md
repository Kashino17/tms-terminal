# Bund Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kein Hauptserver mehr. Alle Geräte sind gleichberechtigt, Gerätebezogenes folgt dem Terminal vorne. Manager, SQL und Watcher fallen weg. Zwischenablage, Snippets und Notizen liegen auf dem Handy. Neue Oberflächen gemäß Mockup v8.

**Architecture:**
- Server: liefert Fähigkeiten (`caps`), Datei-Vorschau ohne Größenablehnung. Manager und Watcher werden entfernt.
- App (RN): Geräte-Routing über `deviceForSession` / `activeDevice`. Kein Primär-Guard mehr. Neue durable Stores.
- Seite: `bund.css` und `bund.js` neben `compact-terminal.*`. Die Bridge versorgt sie mit echten Daten.

**Tech Stack:** Node/TS-Server (node:test), React Native/Expo (TS), WebView-Seite (Vanilla JS), Build `mobile/scripts/build-season2-html.js`, Tests `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-10-bund-design.md`. Freigegebenes Mockup: `mockups/bund-v8/`. Patch-Quellen: `mockups/bund-src/`.

## Global Constraints
- UI-Texte Deutsch, Code und Kommentare Englisch oder Deutsch wie im Umfeld.
- Feste 50 Terminal-Spalten bleiben unangetastet.
- Gerätefarben `#9b8cff`, `#3bc9db`, `#f59f00` nach Position in der gespeicherten Serverliste.
- Durable Speicher über `mobile/src/services/durableStorage.ts` (überlebt APK-Updates und Fold-Neubau).
- Vor jedem Commit, der die Seite betrifft: `cd mobile && npm run build:season2 && npm run test:mockup`. `liquidDeckHtml.ts` mitcommitten.
- Server: `cd server && npx tsc --noEmit && npm test` grün.
- `useSeasonTwoBackends.ts` enthält ein NUL-Byte (Zeile 45). Nur per Shell oder neu schreiben, nicht mit Edit.

## Review Focus
1. **MacBook offline beim App-Start:** Windows-Terminals laufen, Eingaben und Dateien funktionieren, das Mikro ist ausgeblendet. Test: Geräte-Routing-Helfer mit `online:false` für das erste Gerät (Task 4).
2. **Upload gestartet auf WIN, dann zu MAC gewechselt:** Die Datei landet auf WIN, der Pfad in der WIN-Karte. Test in Task 9 (Ziel wird beim Start eingefroren).
3. **Zwischenablage: gleicher Text von zwei Geräten** ergibt einen Eintrag, nach oben gerückt. Angeheftete überleben das Limit 200 und „Verlauf leeren“. Test Task 6.
4. **Windows-Pfad `~\\Desktop` bzw. fehlender Desktop:** Der Explorer fällt auf `~` zurück, statt dauerhaft HTTP 400 zu zeigen. Test Task 2 (resolvePath) und Task 11 (Fallback).
5. **Tastatur auf aufgeklapptem Fold:** Die Seitenleiste bleibt. Geteilter Bildschirm ab Start bleibt ohne Leiste. Test Task 10 (`deskWanted(width, baseH)`).
